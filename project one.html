Project One

HTML + CSS + JavaScript

HTML

HTMLは、Webページの「内容」や「構造」を作るための言語です。

例えば、見出しや文章、画像、ボタンなどを作ることができます。

Hello World!

CSS

CSSは、Webページの「見た目」を変えるために使います。

色、大きさ、位置、背景、レイアウトなどを設定できます。

h1 { color: blue; font-size: 40px; }

JavaScript

JavaScriptは、Webページに「動き」や「機能」を追加するために使います。

ボタンを押したときの処理や、文字を変更するなど、さまざまなことができます。

alert("Hello World!");

まとめ

HTML → Webページの構造
CSS → Webページの見た目
JavaScript → Webページの動き
